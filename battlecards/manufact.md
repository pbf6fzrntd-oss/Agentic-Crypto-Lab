## Summary

Manufact (formerly named **mcp-use**, rebranded after a $6.3M seed round led by Peak XV in February 2026, a Y Combinator S25 company) is a **framework-plus-hosting** platform for building, deploying, testing, and publishing MCP servers and "MCP Apps" for ChatGPT and Claude. It has two parts: (1) **mcp-use**, an open-source TypeScript/Python SDK (6M+ downloads, ~10,600 GitHub stars as of this check) that developers use to scaffold and write MCP server code — tools, resources, prompts, and optional React "Views" for chat-UI rendering — and (2) **Manufact Cloud**, the managed hosting/testing/observability/publishing layer that deploys that code (via GitHub push, CLI, or Manufact's own MCP server) and adds an embedded Inspector, cross-client test suites, analytics, and automated App Store/Connector publishing checks.

**Key differentiator to nail down (confirmed independently, not just from the initial research prompt): Manufact requires the customer to write MCP server code.** Its own quickstart/scaffold (`npx create-mcp-use-app`) generates a project and then has the developer define tools with Zod schemas and handler functions by hand (the docs' own example: "Replace its `index.ts` with a view-bound tool like this," followed by hand-written schema + handler code). Manufact provides scaffolding, hot reload, an Inspector, and deployment infrastructure — it does not, based on everything found this session, auto-convert an existing REST API or database into a working MCP server without code. In that respect it is structurally like **Smithery** (see `battlecards/smithery.md`) rather than like Shredly: both Smithery and Manufact host servers *you build*; Shredly builds the server *for you* from an API/DB/webhook you point it at, with no server code to write. This is the single most load-bearing fact for any Shredly-vs-Manufact conversation and should be led with, not buried.

## Features

Confirmed via search-indexed snippets of manufact.com's own product/platform pages (checked 2026-09-16):

- **mcp-use SDK** (open-source, MIT-licensed, TypeScript + Python) — builds on the official MCP TypeScript SDK v2; adds typed tool-to-UI "Views," a stateless runtime, an embedded Inspector, screenshot verification, and an agent-first CLI. Developer writes server code against this SDK. *(Source: manufact.com/mcp-use, GitHub mcp-use/mcp-use, via search snippets)*
- **GitHub-based deploys** — connect the Manufact GitHub App once; every push to the watched path deploys automatically (reported "under 60 seconds from git push to a live MCP endpoint"); also deployable via `npx mcp-use deploy` CLI or Manufact's own MCP server (agent-drivable). *(Source: manufact.com, docs.mcp-use.com via search snippets)*
- **Preview deployments** — every branch gets its own MCP URL for review before merge (Hobby tier and above per pricing snippets).
- **Embedded/cloud MCP Inspector** — debugger for calling tools, browsing resources, and watching JSON-RPC traffic; also available as a self-hostable open-source Docker image (`mcpuse/inspector` on Docker Hub) independent of Manufact Cloud. *(Source: manufact.com/inspector, docs.mcp-use.com/inspector/self-hosting via search snippets)*
- **Cross-client test suites** — write scenarios/prompts/expected behavior once; Manufact runs them across multiple MCP clients and LLM models (Inspector and ChatGPT supported as of this check; Claude and Cursor listed as "coming soon"), surfacing client- or model-specific regressions. *(Source: manufact.com/platform/cross-client-testing via search snippet)*
- **MCP-native analytics/observability** — usage and reliability dashboards; analytics retention varies by plan (7 days free tier up to 1 year on higher tiers per pricing snippets). *(Source: manufact.com/platform/analytics via search snippet)*
- **Automated publishing checks** — audits an MCP app against ChatGPT Apps Store and Claude/Cloud Connector requirements (protocol, tools, security, app surfaces, domains, listing assets); a "submission pack" generates listing copy, tool justifications, and reviewer test cases (paid tiers). *(Source: manufact.com/platform/publishing-checks, docs.manufact.com/dashboard/publish-checks via search snippets)*
- **Self-hosting option exists but is limited in scope** — per one secondary summary, "hosting your own server is supported through a CLI and Docker images, with health checks before traffic swaps and rollback on failure," and the Inspector specifically ships as a self-hostable Docker image. It is not confirmed whether the full Manufact Cloud feature set (cross-client test suites, publishing checks, analytics) is available self-hosted, or only the Inspector/basic hosting pieces — **flagged as unconfirmed, worth re-checking if a self-hosting-focused prospect raises it.**
- Backing: $6.3M seed round (Feb 2026) led by Peak XV, with Liquid 2 Ventures, Ritual Capital, Pioneer Fund, Y Combinator, True Ventures, and others participating; company targeting $2-3M ARR by end of 2026 per press coverage. *(Sources: VentureBeat, SiliconANGLE, LinkedIn/Vento Ventures announcement — see Sources)*

## Where Shredly wins

- **No code required, period.** Shredly converts an existing REST API, database, or internal tool into a hosted MCP server with no server code to write and no SDK to learn (per CLAUDE.md). Manufact's entire product is built around its own SDK (mcp-use) — the customer writes TypeScript/Python tool definitions, schemas, and handlers, then Manufact hosts and tests what was written. A prospect whose starting point is "I have an API/database, not an MCP codebase" gets a working endpoint faster with Shredly and never touches a scaffold, schema, or handler function.
- **No infrastructure-to-application mental model shift.** Manufact's workflow (scaffold a repo, connect GitHub, write tools, push to deploy, run in an Inspector, pass publishing checks) closely mirrors a general app-deployment workflow (like Vercel/Railway) with MCP-specific tooling layered on top — the customer is still doing software development and shipping a codebase. Shredly's workflow is closer to "point at an existing system, get a key" with nothing to build or maintain as a codebase.
- **Simpler, flatter, better-documented pricing for the SMB buyer.** Shredly: Free / $10 shared / $50 private, three tiers, no metered credits, per-run E2E charges, or team-seat counts to reason about (per CLAUDE.md's confirmed tiers). Manufact's pricing, even accounting for the discrepancies found this session, clearly involves a credit-pool system with per-action metering (E2E checks at $2/run, tool-call requests billed per 1,000, eval runs billed individually) layered under a base subscription — more moving parts for a small team to model cost against before committing.
- **Fits the ICP with no code-ownership burden.** Shredly's ICP (CLAUDE.md) is the AI-team lead at an SMB who wants their data usable by agents without taking on a new codebase to maintain. Manufact, even with generous scaffolding, hands that lead a TypeScript/Python project they now own, test, and version — a maintenance burden Shredly's model avoids entirely.

## Where they win / honest gaps

- **Far deeper testing and publishing tooling.** Manufact's cross-client test suites (run the same scenario across Inspector, ChatGPT, and soon Claude/Cursor, with pass/fail broken out per client/model) and automated App Store/Connector publishing-checklist audits are genuinely more built-out than anything Shredly is described as offering per CLAUDE.md. A team that specifically needs to ship and certify a listed ChatGPT App or Claude Connector, not just an internal MCP endpoint, has real, specific tooling on Manufact's side that Shredly should not claim to match without a real feature to point to.
- **Full control over custom, non-trivial tool logic.** Because the customer writes the actual server code, Manufact supports MCP servers with arbitrary custom logic, multi-step tool composition, and custom UI ("Views") in the chat client — capabilities that go beyond what a schema-driven, no-code API/DB conversion model can express out of the box. A prospect whose "MCP server" is really a bespoke agent-facing product (not just a wrapped API) may outgrow a no-code model faster than a code-first framework.
- **Ecosystem and funding profile.** Manufact is VC-backed ($6.3M seed, YC S25, led by Peak XV as of Feb 2026) and its underlying SDK (mcp-use) has real open-source traction (6M+ downloads, ~10,600 GitHub stars). This is a mindshare/credibility signal a newer or smaller platform doesn't have by default — worth acknowledging rather than disputing.
- **Self-hosting escape hatch.** Because mcp-use and the Inspector are open source (MIT) and Docker-distributable, a Manufact customer who outgrows or wants to leave the hosted product has a documented self-hosting path using the same codebase. Shredly's no-code model, by contrast, does not produce a customer-owned codebase to self-host if the customer later wants to leave — this is a real portability trade-off in Manufact's favor for a technical buyer who values that optionality, and should be conceded rather than argued away.
- **Uncertain, not conceded:** exact pricing figures (Hobby $25 vs $30/credits, Startup $250/month vs $300/credits, Enterprise "$1,000/month" vs pure custom-quote) were inconsistent across sources this session and are not confirmed primary facts — do not concede or repeat these numbers in an external comparison until independently re-verified at manufact.com/pricing.

## Facts

- Manufact (manufact.com) was formerly named mcp-use; it rebranded after raising a $6.3M seed round led by Peak XV in February 2026 (Y Combinator S25 company).
- Manufact's product has two parts: the open-source mcp-use SDK (TypeScript + Python, MIT-licensed, 6M+ downloads, ~10,600 GitHub stars as of 2026-09-16) for building MCP servers, and Manufact Cloud, a managed hosting/testing/observability/publishing platform for deploying them.
- Manufact requires the customer to write MCP server code (tool schemas and handler functions, typically via Zod schemas in TypeScript) using the mcp-use SDK or scaffold (`npx create-mcp-use-app`) — it does not, per everything confirmed this session, auto-convert an existing REST API or database into an MCP server without code.
- Deployment is via a GitHub App (push-to-deploy), a CLI (`npx mcp-use deploy`), or Manufact's own MCP server.
- Manufact features include: an embedded/cloud MCP Inspector (also separately self-hostable via Docker as `mcpuse/inspector`), cross-client test suites (Inspector and ChatGPT supported now; Claude and Cursor listed as coming soon, checked 2026-09-16), MCP-native usage/reliability analytics, and automated publishing checks against ChatGPT Apps Store and Claude/Cloud Connector requirements plus a paid-tier "submission pack" of generated listing assets.
- Reported pricing tiers (search-indexed snippets of manufact.com/pricing, checked 2026-09-16, with unresolved figure discrepancies flagged — re-verify before quoting): Free ($0, ~$5/month credits, 2 projects); Hobby (reported as either $25/month or including $30/month credits, 5 projects, adds preview deployments/E2E checks/submission pack); Startup (reported as either $250/month metered or a $300/month credit allotment, unlimited projects); Enterprise (custom, one source says "starting at $1,000/month").
- Metered add-on pricing observed: E2E checks at $2/run; one source additionally cites $0.10 per 1,000 tool-call requests and $1 per eval run.
- Manufact published a self-comparison blog post, "Best MCP Deployment Platforms 2026: 8 Compared" (manufact.com/blog/best-mcp-deployment-platforms) — this is Manufact's own marketing content comparing itself to competitors and should not be cited as an independent/neutral source.
- Shredly converts an existing REST API, database, or internal tool into a hosted MCP server with no server code for the customer to write (per CLAUDE.md) — the core structural difference from Manufact's code-first, SDK-based model.
- Shredly's pricing tiers (per CLAUDE.md, confirm current numbers at shredly.io/pricing before quoting): Free (Google sign-in, shared environment, base limits); Shared $10/month (shared environment, expanded limits); Private $50/month (private/isolated MCP server, more granular controls).
