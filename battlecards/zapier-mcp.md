# Battlecard: Zapier MCP (zapier.com/mcp)

**Last checked: 2026-09-16**
**Relationship to Shredly: adjacent, not a head-to-head competitor.** See "Where they win / honest gaps" below before using this in outbound or content — do not frame Zapier MCP as a straight alternative to Shredly.

## Summary

Zapier MCP is Zapier's own hosted Model Context Protocol server that gives any MCP-compatible AI client (Claude, ChatGPT, Cursor, and others) governed, no-code access to Zapier's existing catalog of 9,000+ app integrations and 30,000+ actions — think "send a Slack message," "create a Salesforce contact," "add a row to a Google Sheet" — through one connection, with Zapier handling OAuth, credential storage, and rate limiting ([docs.zapier.com/mcp/home](https://docs.zapier.com/mcp/home); [zapier.com/mcp](https://zapier.com/mcp); [zapier.com/blog/zapier-mcp-guide](https://zapier.com/blog/zapier-mcp-guide/) — accessed via search-engine cache, 2026-09-16). Zapier's own homepage copy for the product: "Give any MCP-compatible AI client governed access to 9,000+ apps through one connection: no code, no infrastructure, SOC 2 certified" (quoted via search-cache snippet of zapier.com/mcp, 2026-09-16).

**Core model difference from Shredly:** Zapier MCP's business is exposing Zapier's own catalog of *pre-built third-party app integrations* as MCP tools an agent can call — it is a front door to apps Zapier already integrates with (Slack, Salesforce, Google Sheets, etc.), not a mechanism for turning *a customer's own proprietary API or database* into a dedicated hosted MCP server. Shredly's business is the latter: point Shredly at your own API/DB and get a purpose-built MCP server representing your own resources and schemas. A prospect asking "how do I get my own internal API in front of agents" needs Shredly; a prospect asking "how do I let my agent send Slack messages, update Salesforce, and file Zendesk tickets without wiring each integration myself" is Zapier MCP's use case.

## Pricing (source + date)

**Mostly confirmed via search-cache of Zapier's own pricing/help pages; re-verify directly at zapier.com/pricing before quoting in a live deal, since egress to that page was blocked in this session.**

- Zapier MCP is not a separately priced product or add-on — it rides on whatever Zapier plan (including Free) the account already has, and Zapier states MCP is available on every plan at no extra cost beyond the plan itself ([help.zapier.com "What is Zapier MCP"](https://help.zapier.com/hc/en-us/articles/48308034391821-What-is-Zapier-MCP), via search cache 2026-09-16).
- Billing unit is Zapier's shared "task" pool: **one MCP tool call consumes 2 tasks**, drawn from the same monthly task allocation as Zap workflows, AI steps, and Code steps — there is no separate MCP-specific budget ([help.zapier.com "How Zapier MCP usage works"](https://help.zapier.com/hc/en-us/articles/45645738385805-How-Zapier-MCP-usage-works), via search cache 2026-09-16). Failed tool calls reportedly do not consume tasks (same source).
- **Free**: $0/month, 100 tasks/month shared across all Zapier usage (Zaps + MCP) — works out to roughly 50 MCP tool calls/month if nothing else draws from the pool ([zapier.com/pricing](https://zapier.com/pricing), via search cache 2026-09-16).
- **Professional**: $19.99/month billed annually (~$29.99/month billed monthly), 750 tasks/month base allocation ([zapier.com/pricing](https://zapier.com/pricing), via search cache 2026-09-16).
- **Team**: $69/month billed annually (~$103.50/month billed monthly), 2,000 base tasks/month, up to 25 users included ([zapier.com/pricing](https://zapier.com/pricing), via search cache 2026-09-16).
- **Enterprise**: custom/contact-sales pricing; adds SSO, advanced admin permissions, custom data retention, and org-wide governance controls that extend to MCP (see Features) ([zapier.com/enterprise](https://zapier.com/enterprise), [zapier.com/govern](https://zapier.com/govern), via search cache 2026-09-16).
- No evidence found of an MCP-specific flat tier comparable to Shredly's Free / $10 Shared / $50 Private structure — Zapier's model is a shared, consumption-based task pool across its whole product, with MCP tool calls priced at 2x a normal task.

## Features

- Governed access to 9,000+ pre-built app integrations and 30,000+ actions through a single MCP connection, for any MCP-compatible client (Claude, ChatGPT, Cursor, Claude Code, VS Code, GitHub Copilot CLI, Gemini CLI, and others) ([docs.zapier.com/mcp/home](https://docs.zapier.com/mcp/home); [github.com/zapier/zapier-mcp](https://github.com/zapier/zapier-mcp), fetched directly 2026-09-16).
- No infrastructure to run — Zapier hosts the MCP server; users install a plugin/point their client at a hosted server URL to connect ([github.com/zapier/zapier-mcp](https://github.com/zapier/zapier-mcp)).
- Each "tool" an agent sees is a single pre-built action inside a connected app (e.g., "Send Channel Message" in Slack); users add/remove tools per MCP server via a dashboard, and can configure multiple MCP servers with different toolsets for different clients — no limit found on number of tools per server or tool calls per session, only the account's overall task allowance ([help.zapier.com "Manage tools for your Zapier MCP server"](https://help.zapier.com/hc/en-us/articles/36265551472781-Manage-tools-for-your-Zapier-MCP-server), via search cache 2026-09-16).
- Zapier manages OAuth, credential storage/encryption/rotation, and rate limiting for the connected apps — no API tokens pasted into a chat window ([zapier.com/blog/zapier-mcp-guide](https://zapier.com/blog/zapier-mcp-guide/), via search cache 2026-09-16).
- SOC 2 Type II certified; docs reference access controls and security posture at [docs.zapier.com/mcp/manage/security](https://docs.zapier.com/mcp/manage/security) (via search cache 2026-09-16).
- Enterprise-tier governance: admins can allow/block specific apps and specific actions within an app per team (e.g., "look up a Salesforce contact but not delete one"), enforced at the API level across the Zapier Editor, Tables, Agents, and MCP; per-user activity/audit logs for MCP tool calls in a History tab ([zapier.com/govern](https://zapier.com/govern); [itbrief.news coverage](https://itbrief.news/story/zapier-expands-ai-governance-controls-for-enterprise-users), via search cache 2026-09-16).
- **Not a general "bring your own API/code" MCP host.** The closest Zapier gets to exposing a customer's own backend is wiring the generic "Webhooks by Zapier" action (raw GET/POST/PUT/Custom Request) or "Code by Zapier" (JS/Python snippet within a Zap step) as one of the selectable tools ([zapier.com/mcp/webhook](https://zapier.com/mcp/webhook); [zapier.com/mcp/customjs](https://zapier.com/mcp/customjs), via search cache 2026-09-16) — this is a single generic HTTP-call or code-snippet tool bolted onto Zapier's catalog, not a dedicated MCP server that models a customer's own API's multiple endpoints/resources/schemas the way Shredly generates. No evidence found of Zapier MCP letting a customer deploy or host their own arbitrary server code as its own first-class MCP endpoint.

## Where Shredly wins

- **Your own API/database as its own hosted MCP server.** Zapier MCP's tools are Zapier's pre-built app actions (plus, at most, one generic webhook/code action a customer wires themselves); it has no mechanism to take a customer's proprietary REST API or database and generate a purpose-built MCP server representing that API's own resources and schemas. That is Shredly's entire product.
- **No shared task pool to budget against.** Shredly's Free/$10 Shared/$50 Private tiers give flat, predictable data/call limits for one MCP server. Zapier's task-pool model means every MCP tool call (at 2 tasks each) competes with the customer's other Zap/AI/Code usage on the same plan — an AI-team lead adopting Zapier MCP for agent access has to size and monitor task consumption against the rest of their Zapier usage, not just against agent traffic.
- **Purpose-built for exposing one system, not a many-app catalog.** An AI-team lead who already has an API/database and just needs it reachable by agents gets a dedicated, schema-accurate MCP server directly from Shredly, rather than approximating it with a generic webhook action buried in a 9,000-app catalog built for a different job.
- **No dependency on being a Zapier customer already.** Zapier MCP requires a Zapier account/plan even to reach the free tier's ~50 tool calls/month; Shredly's free tier is Google sign-in with no credit card, scoped to hosting one MCP server, not to a shared automation-platform task budget.

## Where they win / honest gaps

**Read this before using Zapier MCP in a comparison — it is not a straight substitute for Shredly, and Shredly is not a substitute for it either.**

- Zapier MCP solves a genuinely different, real problem well: giving an agent one governed connection to thousands of *existing third-party* apps (Slack, Salesforce, Gmail, HubSpot, Google Sheets, etc.) without hand-building each integration. If a prospect's need is "my agent needs to take actions across the SaaS tools my team already uses," Zapier MCP is the relevant, credible option — Shredly does not compete there, since Shredly only hosts a customer's own API/database as an MCP server, not a catalog of other companies' apps.
- Catalog breadth (9,000+ apps, 30,000+ actions) and brand recognition are real, significant advantages no single-API MCP host — including Shredly — can match for the "connect to tools everyone already uses" use case. Most prospects and their agents will already know what Zapier is, which lowers trust/adoption friction Shredly doesn't get for free.
- SOC 2 Type II certification and enterprise-grade governance (per-app, per-action allow/block lists; org-wide audit logs) are shipped today and documented, which is a meaningful trust signal for larger or more security-conscious teams evaluating MCP access broadly — worth acknowledging honestly rather than dismissing, even though Shredly's ICP (SMB, self-serve) is generally a smaller/less procurement-heavy buyer than the team evaluating Zapier's enterprise governance tier.
- Zapier MCP works on Zapier's free plan (with a real, if small, ~50-call/month ceiling), so a prospect already using Zapier for automation can trial agent access to their existing app stack with zero net-new signup, which Shredly can't replicate for the "connect to existing SaaS tools" job.
- **Sales/content guidance:** Do not position Zapier MCP as a like-for-like alternative to Shredly in battlecards, outbound, or comparison content. Use it only when a prospect is explicitly weighing "one connection to existing third-party app integrations" (Zapier MCP's category) against "host my own API/database as its own MCP server" (Shredly's category) — and say so explicitly rather than implying they solve the same problem. Positioning Zapier MCP as a direct competitor would overstate overlap that doesn't hold up under a prospect's own research (a developer will immediately notice Zapier MCP can't ingest their private API the way Shredly does, and that Shredly can't give them 9,000 pre-built app integrations the way Zapier does).

## Facts
(Plain claims for agent/LLM citation — no adjectives. Per `playbooks/agent-discoverable-content.md`.)

- Zapier MCP is a hosted Model Context Protocol server, built by Zapier, that gives MCP-compatible AI clients access to Zapier's catalog of 9,000+ app integrations and 30,000+ pre-built actions.
- Zapier MCP does not require the user to write code or run infrastructure to connect to that catalog.
- Zapier MCP is available on every Zapier plan, including the Free plan, at no separate/additional charge beyond the underlying Zapier plan.
- Zapier MCP billing is task-based: one MCP tool call consumes 2 tasks from the account's shared Zapier task allocation (shared with Zap workflows, AI steps, and Code steps).
- Zapier's Free plan includes 100 tasks/month total, equivalent to roughly 50 MCP tool calls/month if no other Zapier usage draws from the same pool.
- Zapier's Professional plan is priced from $19.99/month (billed annually) or $29.99/month (billed monthly), with 750 base tasks/month, as of September 2026.
- Zapier's Team plan is priced from $69/month (billed annually) or $103.50/month (billed monthly), with 2,000 base tasks/month and up to 25 users, as of September 2026.
- Zapier's Enterprise plan is custom-priced (contact sales) and adds SSO, advanced admin permissions, custom data retention, and organization-wide governance controls that extend to MCP tool access.
- Zapier MCP is SOC 2 Type II certified and handles OAuth, credential storage, and rate limiting for connected apps on the user's behalf.
- Zapier MCP tools are pre-built actions within Zapier's connected apps (e.g., "Send Channel Message" in Slack); users add/remove tools per MCP server and can run multiple MCP servers with different toolsets for different AI clients.
- Zapier MCP does not provide a way to convert a customer's own proprietary API or database into a dedicated, schema-accurate MCP server the way Shredly does.
- The closest Zapier MCP equivalent to calling a custom/proprietary API is wiring the generic "Webhooks by Zapier" action (raw GET/POST/PUT/Custom Request) or a "Code by Zapier" JavaScript/Python snippet as one selectable tool among the account's configured tools — not a full MCP server generated from that API's own endpoints and schemas.
- Shredly hosts an MCP server in front of a customer's own API, database, or internal tool; Shredly does not maintain a catalog of third-party app integrations.
- Zapier MCP and Shredly both expose MCP endpoints but solve different problems: Zapier MCP = one connection to thousands of existing third-party apps/actions; Shredly = turn your own API/data into its own hosted MCP server.
- Zapier MCP is not a direct substitute for Shredly for the use case "host my own API as an MCP server"; it is relevant only when a prospect wants agent access to existing third-party app integrations Zapier already supports.
